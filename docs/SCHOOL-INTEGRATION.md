## 分层与当前实现

手机界面 → 可配置的 HTTPS 接口网关 → 学校适配器 → 学校系统。手机不保存数据库账号，不直接执行 SQL。若学校开放数据库，应由校内网关使用最小权限账号读取，并通过学校授权的业务接口完成审批；不能直接修改业务表模拟审核。

校方接口、认证和字段约定与通用学生档案分离。手机连接配置在“我的 → 数据管理 → 学校接入”。配置包含根地址、列表/详情/操作/附件路径、字段映射与状态映射。支持不同学校配置自己的网关；学校原始接口不符合下述协议时，只需实现独立适配器，不能假设改一个网址就能复用任意学校的登录和流程。

## 与 NNUAutoLeave 的关系

参考 `G:\onedrive\smallprjs\Dev_NNUAutoLeave\auto-leave.mjs` 和 README 的实际代码：它通过已登录浏览器读取 EMAP 表格，使用 WID、USER_ID、TASKID、NODEID 等字段，向 EMAP 流程接口提交销假同意。FLOWSTATUS=1 在该销假审核页表示待办，不能将它泛化为所有请假的“待审批”。USER_ID 未证实为学号，当前不冒充学号。

本项目没有运行或导入原项目的定时任务、自动重登录和批量同意脚本，也没有读取它的账号、配置、日志或浏览器 Profile。新增适配器独立使用自己的浏览器 Profile，手动登录后才能主动同步。一次只处理用户明确确认的一条待办，提交前重新核对任务标识。

南师大适配器当前返回 `complete:false`：只读当前页，不代表完整学生名册或完整历史。尚未取得附件、完整历史、请假审批、假别和地域接口，因此不会编造字段或宣称这些能力已接通。待核销假也不自动等于已核实在校。

## 网关协议

默认路径可在手机配置中修改；`{id}`、`{fileId}`由客户端编码替换。列表及详情使用GET，操作使用POST；其他学校的非标准调用在网关适配。

### GET /leaves

```json
{
  "records": [{
    "id": "leave-1001",
    "studentId": "school-internal-id",
    "studentName": "示例学生",
    "studentNumber": "20260001",
    "status": "待销假",
    "startAt": "2026-11-13T09:00",
    "endAt": "2026-11-13T18:00",
    "summary": "考试",
    "destination": "南京市",
    "region": "江苏省",
    "attachments": [{"id":"proof-1","name":"证明.pdf","mime":"application/pdf"}]
  }],
  "complete": false,
  "total": null,
  "capabilities": ["close", "attachments"]
}
```

`id`和`studentId`必须稳定唯一，学校数据加`school:`前缀与本地示例隔离。列表ID重复、缺少ID或响应格式错误时，拒绝覆盖已同步数据。网关自行汇集分页；只有当前授权范围的记录全部取完才可声明`complete:true`。手机不根据当前页推算全校人数或全历史发生率。

支持状态：待审批、已批准、请假中、待销假、已销假、已驳回。未知状态显示“校方状态未知”，不能自动当待审批。字段映射支持点路径，例如 `fields.status="flow.code"`；状态映射例如 `statuses={"RETURN_PENDING":"待销假"}`。附件数组保持`id/name/mime`协议。起止时间建议提供学校本地时间 `YYYY-MM-DDTHH:mm`，日期或精度不足不能用于推断实际离校。

### GET /leaves/{id}

响应为 `{"record": {...}}`，字段同列表。详情ID必须匹配请求ID；用于刷新校方状态和获得完整附件清单。

### POST /leaves/{id}/actions

```json
{"action":"close","comment":"已核实返校材料，同意销假"}
```

只展示网关声明的能力与当前状态允许的动作交集：`approve/reject/depart/return/close`。用户先选择动作，再填写意见并确认提交。网关必须依据当前登录用户、任务权限和最新状态重新校验，不能相信手机的状态。

返回 `{"accepted":true,"verified":false}` 只代表接收操作；手机随后重新读取列表，不乐观修改校方状态。超时或刷新失败会提示先核实，不自动重试。南师大适配器在进程内阻止同一任务重复或结果未知的再次提交；这不代替校方幂等和持久审计。正式网关应提供持久化幂等键、权限审计与结果查询。

### GET /leaves/{id}/attachments/{fileId}

返回经校方鉴权后的文件字节，而不是把 Cookie 拼到链接。客户端使用同一网关令牌获取；按文件头识别 PNG/JPEG/PDF 预览，其他格式下载，不执行HTML。南师大当前此接口返回501，待取得真实附件接口后再实现。

预览使用设备内弹层；PDF依赖浏览器内置支持，真机尚未验证，始终保留下载入口。Office及音视频等其他格式交由设备应用打开，不上传到第三方转换服务。

## 本地连接器运行

安装手机工程依赖后，在 PowerShell 为当前进程设置连接器令牌（至少24字符，自行生成，不提交或发送给他人）：

```powershell
$env:SC_SCHOOL_BRIDGE_TOKEN = '<你生成的随机令牌>'
npm --prefix mobile run school:bridge
```

默认只监听 `http://127.0.0.1:4175`，允许的手机开发页面来源为 `http://127.0.0.1:4176`；可通过 `SC_SCHOOL_BRIDGE_PORT`、`SC_SCHOOL_UI_ORIGIN`、`SC_SCHOOL_BROWSER` 调整。默认使用Edge，改为Chrome可设置 `SC_SCHOOL_BROWSER=chrome`。

在学校接入选择南师大预设，填写同一令牌并保存，点“建立校方会话”，在弹出的电脑浏览器中手动登录并进入销假待办页，再点“同步校方记录”。连接器不会自动运行浏览器、登录、同步或审核。校方验证码、会话失效需要人工处理。

Profile保存在仓库忽略目录 `.local-data/school-browser`。这是浏览器持久登录资料，不是桌面加密快照；不共享、不纳入安装包。临时网关令牌与手机数据仅在进程/页面内存中，刷新或退出后需重新配置。

## 真机与后续部署

手机上的127.0.0.1指手机自身，不能连到电脑本地连接器。真实手机需学校批准的HTTPS网关及可访问的身份认证，设置为该网关地址。不能简单把当前连接器改为0.0.0.0公开上网；正式网关需账号鉴权、校方授权、限流、服务端审计、持久幂等和加密资料库。

当前没有部署公网服务、连接正式学校数据库、制作手机安装包或完成真实学校联调。AI默认无网络请求；学校连接只在用户主动点击时请求配置的地址。统计按已同步记录展示，缺少地域不地理编码、不推断学生位置；频次按获批申请的开始日期计数，时间范围不改变当前状态名单。

大规模接入还需服务端按日期分页及聚合统计，不应把学校全库一次下载到手机。记录完整性与完整学生名册也应分别提供；当前学生状态名单仅覆盖已同步记录关联的人，不等于全校名册。
