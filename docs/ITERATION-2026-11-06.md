## 复用与数据边界

拖拽使用 React Grid Layout 1.5.4，表格使用 TanStack Table，图表使用 Recharts，导出使用 ExcelJS 和 JSZip。

附件不进入数据库或 localStorage。用户主动选择的文件只以本次会话 File 对象关联，已有路径保存元数据并明确区分可读状态。导出包按行号关联附件，去重、命名冲突与范围外排除由统一逻辑处理；无法读取的路径列入缺失清单。

工作留痕根据真实操作生成，不把既有演示记录推断成用户当天完成。每日简报可将操作和待办传给用户配置的兼容模型，经确认后发送；回复以草稿保存，不自动修改业务决定。密钥仅在内存中。

正式加密账套、目录授权、迁移与物理重命名、Excel 导入、富文本尚待底层阶段实现。浏览器原型不代替正式数据存储。
