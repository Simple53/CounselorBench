# 字号与交互细化

本轮以用户明确修改为基准，原大字号图稿不再作为字体尺寸依据。

## 实现

- `density.css` 统一 14px 正文/导航、16–20px 标题，移除原大屏放大规则；旧 UI 配置首次迁移重置为14px，后续尊重用户字号选择。
- `public/assets/workbench-icon.svg` 使用档案夹、清单与管理网格，用于左上角与 favicon。
- 侧栏平铺学生相关模块，仅个人工作分组；学生表行数可选，预览改为 React 对话框。
- `SearchSelect.jsx` 提供搜索和新增，关联学生必须选择有效 ID；新增学生需学号，状态/模块可扩展。修复首次输入被默认值同步清空的问题。
- 附件管理仅位于设置；可配置资料根目录，但浏览器原型不会移动磁盘文件。
- `Psychology.jsx` 独立演示关注名单和谈话记录，蓝/橙/红颜色对应人工关注等级。周期无内置临床默认值，由使用者设置；显示首次谈话、近期、到期与逾期状态。
- 关注名单与谈话当前会话跨页面保留；最近已完成谈话更新下次日期。普通留痕不保存谈话标题和敏感附件引用。
- AI 面板位置根据球坐标和视口边界计算，固定模式仍可使用；新增本地模型与云端兼容模板，配置不触发网络请求。

## 验证

`npm run build` 成功，9 项逻辑测试通过。实际 Edge 浏览器验证 1536px/1920px 下均为14px导航、20行分页、无新标签预览、搜索新增、相邻AI面板、设置路径、本地预设、谈话周期及隐私范围。

最终结果：`output/playwright/refinement-results.json`；截图以 `refinement-` 为前缀。首页截图等待网格稳定，并检查所有组件无重叠；初次进入网格过渡动画不作为最终视觉状态。

仍未接入正式加密工作账套；心理内容只适合使用虚构资料验证，刷新后业务数据重置。

## 照片、列筛选与简报汇编

- 首页默认六个入口：学生信息、日常管理、学风建设、资助育人、心理健康、工作留痕。仍可拖动、缩放、移除或添加入口；旧布局首次补齐入口并保留原有组件。
- 学生姓名旁和详情面板可进入照片管理，多图导入（单张上限20MB）、查看原图、设置肖像及移除关联。照片文件复用独立附件注册表；学生行只保存照片/肖像ID，导出随该学生的附件关联打包。移除关联不会删除其他记录引用的文件。
- 列菜单参考微软 Excel AutoFilter 的搜索、值列表、排序及自定义条件，同时增加反选。搜索限定可见选项，应用时按搜索结果与已选值交集筛选；条件支持且/或、空值、文本及数值/日期比较。条件与值列表共同生效；取消不修改已应用筛选。
- 工作留痕支持每日简报、综合文档、月历；汇编按日期范围输出本次会话的实际操作和已保存AI草稿，可下载Markdown。待办使用当前状态，不冒充已持久化的历史快照。日历点击日期进入当天简报。
- Excel 参考：https://support.microsoft.com/en-us/excel/quick-start-filter-data-by-using-an-autofilter

业务数据、照片文件与简报当前仍在会话内；UI偏好单独本地保存。

本轮最终验证：构建通过、9项逻辑测试通过；Edge 实测照片实际ZIP、筛选反选/条件组合、汇编下载与日历切换通过，浏览器脚本错误为 `[]`。证据：`output/playwright/latest-results.json` 和 `latest-*.png`。
