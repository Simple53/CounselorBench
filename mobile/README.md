# 辅智通手机界面

2026-11-14：统一调试入口为 [手机/Android/平板/电脑预览](http://127.0.0.1:4178/debug.html)。首页仅保留可编辑增减组件的数据概览，不再放视图切换或独立请假区；宿舍视图进入学生信息查看，学校链接位于服务。学校账号、密码和默认自动只读同步放在我的/数据管理/学校接入。南师大支持独立连接器按校方表单登录，其他高校当前按可配置网关令牌认证，非标准认证需独立适配。

真实学校HTTPS入口本轮返回HTTP412，未进入登录页、未读取学生数据或审批。账号密码仅当前会话内存，跨重启加密保存未实现。以下旧版本首页功能描述以本段为准。

独立的 React/TypeScript 手机交互原型，保留桌面工程。预览首页、服务、待办、我的四个入口，支持 iPhone 和 Pixel 10 设备切换。

## 已实现

- 首页六项默认统计、展开统计、专业分布；统计来自当前示例数据。
- 服务四列白底方块，学生工作与个人工作分开；请假销假作为独立模块。
- 学生搜索、详情、肖像预览；业务记录搜索、状态和日期筛选、排序、新增、附件选择及 JSON 导出。
- 请假申请、审批、离校、返校、销假；时间合法性、重叠申请和逾期校验，与学生在校状态联动。
- 待办完成、消息已读、操作留痕；可拖动 AI 球与当前模块建议。
- 顶部无重复品牌区；我的直接显示外观显示、AI配置、数据管理。附件管理与学校接入位于数据管理内。
- 首页、待办、业务记录与工作留痕支持日历视图；首页可配置请假状态、频次、去向和月份统计。
- 学校连接支持自定义HTTPS网关和字段/状态映射；南师大适配层与通用界面分离，主动同步并人工单条销假。详细协议与运行方法见[学校接入说明](../docs/SCHOOL-INTEGRATION.md)。

## 当前边界

这是界面与交互验证工程，不是 APK/IPA。数据、照片、附件和模型配置仅保存在本次页面内存，刷新重置。AI建议为本地规则，没有发起模型请求。学校连接仅在主动点击时访问配置的接口，不自动上传或同步。南师大当前只支持当前页待办与单条销假审核，完整历史和附件尚待实际接口确认。尚未连接桌面加密资料库、手机文件系统、后台提醒或多人协作。JSON导出仅含文件元数据，不能替代桌面附件打包。不能用此预览录入唯一副本的真实资料。

## 开发

在上级目录执行 `npm run mobile:dev`，默认地址 http://127.0.0.1:4176 。依赖安装：`npm --prefix mobile ci`。构建：`npm run mobile:build`。构建入口为 `mobile/dist/client/index.html`，需要 HTTP 服务访问，不支持直接双击文件。

运行 `npm --prefix mobile run check:runtime` 校验受保护设备运行时；`npm --prefix mobile run test:sites` 校验静态服务产物。`npm --prefix mobile run test:runtime` 运行手势、键盘和安全区回归，需要 Playwright 浏览器。

手机业务代码位于 `src/Prototype.tsx`、`src/prototype.css`、`src/domain.ts`；复用上级 `src/model.mjs`、`src/leave.mjs` 与模型预设。设备壳、键盘、安全区、基础滚动和构建运行时保持模板原样。
