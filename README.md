# CounselorBench · 辅导员工作台

已接入本地用户与加密存储的开发版本：React、Vite、Tabler Icons、TanStack Table v8、Recharts、React Grid Layout、ExcelJS、JSZip。


## 安装版本

[下载多系统安装包](https://github.com/Simple53/CounselorBench/releases)。Windows支持安装版与便携版，macOS支持Intel和Apple Silicon，Linux提供AppImage/deb/rpm。

桌面端采用Electron并内置本地服务，安装后不需要Node.js。登录使用**用户名、密码**；首次点击“创建用户”，忘记密码可用恢复密钥重设。用户数据和附件独立加密保存在本机，不上传GitHub。

发布流程、保存目录、签名限制见[桌面发布说明](docs/DESKTOP-RELEASE.md)。原SQLCipher/Tauri架构仍待后续迁移，本版底层为Node加密快照。

## 启动

双击项目或上层目录中的 **启动工作台.cmd**，启动器按需构建并打开 http://127.0.0.1:4173/ 。源码入口在 `index.html`，构建入口在 `dist/client/index.html`；不能通过双击HTML运行。`npm start` 等效。

默认数据保存在 `%LOCALAPPDATA%/SmartCounselor/workspaces`，与当前OneDrive项目分离。新用户资料为空；演示模式不保存。密码、恢复密钥、附件、备份和范围见 [本地账套说明](docs/LOCAL-WORKSPACE.md)。

## 当前功能

- 首页组件自由拖拽、边缘缩放、网格吸附；可添加数据组件和板块入口，保存布局。
- 15 个四字板块导航（包括学生信息、工作留痕）、学生全览、日历叠加及事件详情。
- 学生及业务共用表格、列筛选、多条件 AND/OR、多列排序、时间跨度、分页；字段组合及增删改模板。
- 学生详情只在学生信息显示；右下角可选行数；双击在页内对话框预览。
- 新增学生、业务记录可添加任意格式文件、登记路径或关联已有附件；统一管理和重新关联文件。
- XLSX、CSV、HTML、JSON 加附件 ZIP 导出，包含导出行关联、去重和缺失文件清单。
- 工作留痕按实际新增、完成、附件操作及导出生成，汇总每日完成和待办；AI 每日简报可保存草稿。
- AI 球可移动，面板可固定；各板块规则建议、API/模型配置及主动确认后的兼容模型调用。
- 主题、字号、板块显隐及自定义四字板块。
- 默认正文/导航 14px、标题 16–20px，不随大屏额外放大；本地SVG管理图标。
- 本地用户注册/登录、随机数据密钥、独立恢复密钥、AES-GCM快照和独立附件持久化，失败重试和版本冲突保护。
- 一致性加密ZIP备份；刷新或锁定后重新打开，学生、照片、业务、心理台账、工作留痕和简报均可保留。
- 侧栏仅区分学生工作与个人工作，附件管理移入设置，可保存资料根目录配置（不实际移动磁盘文件）。
- 新增记录的选择器支持搜索、新增学生及选项；心理关注等级、周期设置、谈话登记及到期提醒可使用虚构资料验证。
- AI 浮动面板紧邻悬浮球，增加 Ollama、LM Studio、llama.cpp、LocalAI、vLLM 等本地预设。

## 原型边界

演示模式使用虚构数据并在刷新后重置；本地用户模式自动加密保存业务、照片、留痕、简报、字段模板和偏好，不再把用户偏好写入localStorage。API 密钥仅在内存保存，只有用户确认目标及内容后才发送模型请求。勿录入真实学生资料。

SQLCipher、本地目录授权、文件迁移/物理重命名、Excel 导入、富文本、完整字段和板块重命名/排序、正式统计口径尚未接入。浏览器原型不是正式桌面安全系统。

只有用户主动选择的文件可真实打包；仅登记的系统路径不可直接读取，需重新关联，未关联者明确列入缺失清单。心理台账已开放演示，实际内容与附件不进入公共记录或普通附件管理；本地用户模式已做文件级认证加密及密码解锁，尚未实现心理模块独立身份认证。AI 面板中的常驻建议为本地规则，模型回复另标为草稿。

本地预设采用兼容接口，参考 [Ollama 文档](https://docs.ollama.com/api/openai-compatibility) 与 [LM Studio 文档](https://lmstudio.ai/docs/developer/openai-compat)。模板不会安装、下载或自动连接模型，须自行启动服务并填写实际模型名称。

当前本地层是Node标准库实现的加密快照适配器，不等同于SQLCipher。后续迁移至Windows桌面壳与SQLCipher关系表；附件接口和数据密钥模型延续。附件保持根目录编号和相对路径索引，二进制不进入数据库。没有部署云端；模板托管构建能力仅保留兼容性。
